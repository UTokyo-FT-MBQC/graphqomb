# Steane logical T injection

```sh
uv run python -m examples.ftqc.steane_t_injection
```

The example exports `steane_t_injection_x.ptn`, `steane_t_injection_z.ptn`,
and `steane_t_injection_quantum.ptn` to the gitignored `output/` directory.
The figure is exported as `steane_t_injection.png`, `.pdf`, and `.svg`.

The `.ptn` files preserve Clifford flows, schedules, detector seeds, and
logical-observable seeds. Encoded data and magic input states are supplied by
`steane_input()` in Python; the Pauli-only initialization metadata in `.ptn`
cannot describe them. Default product inputs do not reproduce this experiment.

## Figure: steane-t-injection

Panel (a) follows the logical operation from left to right: first syndrome
round, logical ZZ measurement, second syndrome round, S/Z correction, and
logical X readout. The separate magic block is consumed by X measurement.

Panel (b) shows all 56 resource nodes in XYZ coordinates. The seven data
positions remain fixed in the XY plane, and their five foliation copies are
stacked at Z = 0, 1, 2, 3.5, and 5. Syndrome ancillas sit above the data plane
whose checks they extract. The rotated magic patch is read out at Z = 2.5;
the ZZ probe is at Z = 2.25 and the delayed record relay at Z = 4.5.
Z identifies logical operation layers, rather than the compiler's individual
TICK slices. The actual sequential schedule is exported separately.

Solid lines are CZ gates. Orange lines connect the logical-Z boundaries to
the ZZ probe. Blue, purple, and green arrows show the p relay, conditional
S correction, and logical Z correction from the magic parity m. Panel (c)
shows the XY code patch with physical qubit labels and stabilizer faces.
Faces define code supports and are not quantum gates.

The figure is generated by `_support/steane_layout.py` from the saved 3D
coordinates in `_support/steane.py`, and displayed by `steane_t_injection.py`.
The `.ptn` exports retain all three coordinate components. PNG, PDF, and
editable-text SVG exports use Matplotlib's default DejaVu Sans font.
The triangular plaquettes follow the seven-qubit color-code geometry in
[Postler et al., Fig. 1(c)](https://doi.org/10.1103/PRXQuantum.5.030326),
with labels matched to this example's stabilizer supports.

The Steane example uses X and Z stabilizer generators on the supports
`{0,1,2,3}`, `{0,1,4,5}`, and `{0,2,4,6}`. Logical X and Z have support
`{4,5,6}`. Logical zero is the equal superposition of the eight words in the
simplex row space, and logical one is the complement coset.

The 56-node resource contains two non-destructive syndrome rounds, an encoded
seven-qubit magic input, a logical ZZ probe, and a delayed correction control.
The input register contains seven encoded data qubits, seven encoded magic
qubits, and one `|0>` control. Each syndrome round uses a sequential schedule;
the complete pattern has at most 16 live qubits. The X/Z variants measure all
seven data outputs, while the quantum variant leaves them unmeasured.

The probe is connected to the three-qubit logical Z supports of the data and
magic blocks. Its X measurement projects logical `Z_L Z_L` with bit `p`.
Consuming all magic qubits by X measurement gives logical X bit `m`, the
parity on `{4,5,6}`. The uncorrected logical branch is

```text
Z_L^m T_L^(+1) |psi_L>   if p = 0
Z_L^m T_L^(-1) |psi_L>   if p = 1
```

Logical `Z_L^m` feedforward is sent from the three magic records to the
three-qubit logical Z support on the final data. The logical S correction uses
physical `(S^dagger)^tensor7`: weight-0/4 simplex words acquire phase 1, while
weight-3/7 logical-one words acquire phase i. This convention is tested
explicitly; using physical S instead would implement logical S-dagger.

Node 35 is an implementation relay, not a required qubit in logical T
injection. The current Clifford frame checks noncommuting correction order
through the correction dependency DAG. A direct correction controlled by the
ZZ record cannot express the later S event after all foliation Pauli events.
The auxiliary node copies that existing bit and supplies a later record.

The probe controls X on the auxiliary `|0>` input. Measuring this input in Z
copies `p` into a single delayed measurement record. Z feedforward from all
earlier measurements to this input imposes the ordering after both syndrome
rounds without changing the copied bit. Its record controls the seven physical
S-dagger corrections. This makes the S correction occur after the foliation's
noncommuting Pauli corrections within the current single-record cflow API.

The six repeated detectors compare corresponding ancilla records before and
after injection. Three final detectors are the readout parities on the
stabilizer supports, and the logical observable is the parity on `{4,5,6}`.
Three further detectors use magic X records on `{0,1,2,3}`, `{0,1,4,5}`,
and `{0,2,4,6}`. All seven magic qubits participate, including the four outside
the chosen weight-three logical-Z support. Their input state is encoded and
entangled; it is not seven independent T states. All twelve detectors are
zero in the ideal encoded readout experiment. The X readout
adapts between X and Y according to `p`; Z readout preserves its axis.

## Feedforward backpropagation

`build_steane_pattern(...)` creates a `Feedforward` IR
containing the correction maps, detector supports, logical-observable supports,
and tags. It calls `feedforward.backpropagate(graph)` before `qompile`, retaining
the example's sequential schedule and at most 16 live qubits. The gallery and
exported patterns use this path.
The quantum-output variant retains its output frame and has no classical
logical-observable annotation, because its data qubits are not measured.

The transform stops at the backward closure of Clifford targets and keeps
their Pauli and Clifford dependencies executable. Final-data detectors and the
logical observable remain parities of adapted boundary records, including for
Z readout. Retained corrections are not counted again in their supports.
The example prints these stored supports directly; it does not ask the older
frame raw-record analysis methods to expand through conditional S.

Tests compile and execute both readout variants, check all twelve detector
parities and the logical observable from the compiled supports, and retain
conditional S. These are supported boundary-preserving transformations,
replacing the four previous expected failures. General Clifford-dependent
nominal-basis expansion and encoded-input determinism certification remain
separate unsupported operations.

The sampled detector and logical parities are evaluated directly from the
compiled supports and compared with independent logical-gate and fault-column
predictions. There is no separate hand-written parity implementation or
uncompiled example path. These checks do not certify graph-state determinism
for the encoded inputs. Stim export still rejects nontrivial cflow.

Validation checks logical T output fidelity for 16 Born-sampled executions,
including all four `(p,m)` branches. It also checks 336 single-Pauli-fault
executions, covering both readouts, every data qubit, every Pauli axis, and both
ZZ branches. These faults are inserted after the second syndrome round, so
they change only the final detector column and, when supported, the logical
parity. Tests verify deterministic positive and negative logical X/Z results
using single-logical-qubit T-gate predictions, and execute patterns after
file-based `.ptn` round trips. Single Z faults immediately before X measurement
on each of the seven magic qubits are also checked against independent columns
of the stabilizer parity matrix.

```sh
uv run pytest tests/test_ftqc_steane_t_injection.py
```

The encoded inputs are ideal resources. The demo measures syndromes without
decoding or applying error recovery; it does not implement fault-tolerant
resource preparation or claim circuit-level fault tolerance.
